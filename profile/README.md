## What we build

<table>
  <tr>
    <td width="33%" valign="top">
      <strong>💵 Pay-in</strong><br><br>
      Accept cash, bank transfers and local payment methods. Single API
      across countries; payment-method routing per country and merchant.
    </td>
    <td width="33%" valign="top">
      <strong>🏦 Pay-out</strong><br><br>
      Disburse to bank accounts or to cash pickup at agent networks.
      Settlement in local currency, on a single ledger.
    </td>
    <td width="33%" valign="top">
      <strong>🌎 Remittances</strong><br><br>
      Cross-border send flows with KYC, FX quoting and local-rail payout.
      Built for consumer-grade UX.
    </td>
  </tr>
  <tr>
    <td width="33%" valign="top">
      <strong>🧩 Partner platform</strong><br><br>
      Self-service onboarding, organization-level RBAC, API keys and a
      real-time view into transactions, settlements and reconciliation.
    </td>
    <td width="33%" valign="top">
      <strong>📍 Agent network</strong><br><br>
      A mobile app that turns local merchants into cash-in and cash-out
      points. Geo-routed, with live availability.
    </td>
    <td width="33%" valign="top">
      <strong>🛡️ Compliance built-in</strong><br><br>
      KYC, country-specific limits, AML controls and audit trails —
      designed against LATAM regulatory reality.
    </td>
  </tr>
</table>
